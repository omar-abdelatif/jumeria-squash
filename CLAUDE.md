## ✅ SEO & Architecture Standards (CRITICAL)

- **NEVER** use dynamic folder names for routes (e.g., `[slug]`, `[id]`).
- **ALWAYS** use the root `app` folder or `app/(` slug`)` for dynamic routes.
- **NEVER** place content pages in `app/(marketing)/...` — these are for layout groups.
- All pages must have proper **Metadata** and **OpenGraph** tags.
- All pages must have **canonical** URLs.
- All pages must have proper **Open Graph** and **Twitter Card** tags for social sharing.
- All pages must have proper **keywords** meta tags.
